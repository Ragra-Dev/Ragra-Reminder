# Ragra Personal Edition

## Goal
Turn fragmented academic information into an automatically maintained system of:
source -> task/deadline -> personal plan -> reminder -> completion -> history -> optional AI planning.

## User
Initially one user: the developer, FAST-NUCES Islamabad.

## P0 — must work
1. Google Classroom connection
2. Classroom sync
3. Assignment/announcement/material discovery
4. Actual deadline extraction
5. Personal completion targets
6. Task database
7. Reminder engine
8. Completion and missed states
9. Reminder notifications (pluggable provider; optional personal Hermes integration)
10. Daily schedule
11. Google Calendar sync

## P1
- FAST timetable integration
- 15-minute class reminders
- cancellation/rescheduling detection
- 7 AM morning brief
- Apple Calendar via ICS if useful

## P2
- AI actionable/informational classification
- difficulty/workload estimation
- weekly planning
- multi-week planning
- rescheduling
- AI chat

## P3
- semester analytics
- multi-university support
- public SaaS
- billing/ads

## Product rule
Every feature should reduce manual academic tracking. If a feature does not do that, question it.
